# A/B-тест: приносит ли рассылка дополнительные покупки?

Проект продуктовой аналитики на реальном рандомизированном эксперименте Hillstrom / MineThatData. Сравниваем рассылку `Mens E-Mail` с отсутствием письма, оцениваем дополнительную выручку на назначенного покупателя за 14 дней.

**[Отчёт и выводы](results/report.md)** · [Выполненный notebook](analysis.ipynb) · [План эксперимента и решения](docs/design.md)

## Запуск

Из папки проекта в PowerShell, Python 3.14:

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m unittest -v
./.venv/Scripts/python.exe ab_test.py
./.venv/Scripts/python.exe make_notebook.py
```

Linux/macOS: `.venv/bin/python` вместо `.venv/Scripts/python.exe`. Для точного окружения используй `requirements-lock.txt`. Исходный CSV и его SHA-256 сохранены: повторный анализ выполняется без загрузки данных. `--refresh` повторно получает открытый CSV по исходной HTTP-ссылке автора; исторический HTTPS-сертификат сайта недействителен.

## Что сделано

- Зафиксированы гипотеза, основная метрика и метод до просмотра результатов.
- Рассчитан размер выборки будущего теста при заданных alpha, power и MDE.
- Сохранено оригинальное назначение пользователей; нулевые покупки не исключены.
- Выполнены Welch t-test, Mann–Whitney и bootstrap с разной интерпретацией результатов.
- Проверены размеры групп (SRM) и баланс предэкспериментальных признаков.
- Применена CUPED / ANCOVA-корректировка по истории покупок с HC3-ошибками.
- Реализован хэш-сплит с солью и учебная A/A-диагностика на группе без воздействия.
- Подготовлены графики, выполненный notebook и текст для анкеты.

```text
ab_test.py            воспроизводимый расчёт и отчёт
test_ab_test.py       проверки статистики и целостности данных
make_notebook.py      создание и выполнение объясняющего notebook
docs/design.md        зафиксированный план и история решений
data/raw/            неизменённый исходный CSV и источник
data/processed/      выбранные A/B-группы с техническим ID строки
results/             эффекты, интервалы, p-value, расчёт выборки и графики
```

Исторический эксперимент проведён автором данных; здесь выполнен повторный анализ и подготовлен дизайн аналогичного будущего запуска. Учебный A/A не является live-экспериментом. Основное решение основано на Welch для средней выручки; Mann–Whitney не используется как тест среднего. Маржа, отписки и расходы отсутствуют, поэтому рост выручки не объявляется ростом прибыли.
